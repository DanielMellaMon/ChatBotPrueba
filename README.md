# ChatBot creado para ver la funcionalidad de esta y su entendimiento

Un chatbot de asistencia personal construido con React y conectado a una IA real mediante la API de Groq (LLaMA 3.3).

## Tecnologías usadas

- React (Create React App)
- JavaScript (ES6+)
- CSS3
- Groq API (LLaMA 3.3-70b)

## Funcionalidades

- Chat en tiempo real con IA
- Historial de conversación
- Indicador de escritura mientras la IA responde
- Diseño minimalista dark mode

## Instalación y uso

1. Clona el repositorio y entra a la carpeta
2. Instala las dependencias con `npm install`
3. Crea un archivo `.env` con tu key: `REACT_APP_GROQ_KEY=tu_api_key`
4. Inicia la app con `npm start`

## API Key

Obtén una key gratuita en [console.groq.com](https://console.groq.com)
